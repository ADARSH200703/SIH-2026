HOW IT WORKS

Telemetry to Health Intelligence

Six-stage continuous evaluation cycle running at up to 20Hz on the ground station backend.

01

INGESTION

Engine telemetry packets arrive via continuous WebSocket or REST stream (or controlled test scenario in Simulation mode).

02

VALIDATION

Each channel undergoes range, noise, frozen-signal, and drift checks to compute the aggregate Sensor Trust Score.

03

PHYSICS TWIN

Physics model computes expected engine state under current throttle/altitude and evaluates normalized residuals (Δ, σ, slope).

04

DIAGNOSIS

Isolation Forest and physics rules classify anomalies into specific failure modes with multi-source consensus confirmation.

05

PROGNOSTICS

Degradation dynamics estimate Remaining Useful Life (RUL) hours and evaluate mission reliability risk.

06

DECISION

GCS displays actionable status, explainable evidence chains ("Why?"), and automated mitigation telecommands.

DATA MODES

Operating Modes

Strictly segregated data modes with distinct visual indicators.

LIVE

Live Telemetry

Consumes real incoming telemetry packets. If the stream stops or is absent, the system indicates WAITING / DISCONNECTED rather than showing synthetic fallback data.

science SIMULATION

Simulation / Test Mode

Deterministic physics simulation for testing failure injections (bearing wear, cylinder overheat, lubrication loss, misfire). Clearly watermarked as SIMULATED.

replay REPLAY

Historical Replay

Replays recorded session telemetry from the database with scrubbing and speed controls for post-mission incident analysis and verification.
